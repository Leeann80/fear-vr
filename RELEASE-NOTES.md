# F.E.A.R. VR v0.1.0 — first public release

This is the first public distribution of the original F.E.A.R. PC VR mod,
following the private RC6.2 beta. It uses the same accepted campaign gameplay
baseline, with corrected startup diagnostics, native application icons, and
expanded player documentation.

## Features

- Tracked head/hands, stereo presentation, controller aiming, and comfort options.
- Physical **Grip & Holsters** or **Classic Sticky** weapon handling.
- Manual reload, physical interactions, ladder recovery safeguards, and contextual tutorials.
- Height, hand/controller, holster/pouch, weapon-grip, and sight calibration.
- Configurable handedness and button roles, with saved layouts and resets.
- Native install, direct beta upgrade, uninstall, and interrupted-operation recovery.
- Alma artwork embedded in Setup and the VR launcher.
- Offline installation, controls, calibration, troubleshooting, limitations,
  security, and third-party guides in the package and installed help folder.

## Updating from RC6.2

Quit F.E.A.R., extract the complete new ZIP into a new folder, and run its Setup.
Choose **Upgrade F.E.A.R. VR**. Original backup lineage and saves are preserved;
modified managed files are saved before replacement. Do not manually combine
files from the old and new archives.

## Before playing

Read [Installation](INSTALLATION.md), [Controls](CONTROLS.md), and
[Known limitations](KNOWN-LIMITATIONS.md). The supported game is the GOG base
campaign on Windows, with Virtual Desktop + VDXR or a usable Win32 SteamVR
OpenXR route. Quest 3/Touch is the physical validation baseline.

The mod and updates are free. This GitHub repository distributes binaries and
documentation; the mod's source code is not being released.
